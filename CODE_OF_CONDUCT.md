# code of conduct

This project aims for respectful, direct, technically grounded collaboration.

## expected behavior

- critique ideas and evidence, not people;
- disclose conflicts of interest;
- respect repository maintainers;
- avoid harassment;
- avoid posting private or sensitive information;
- use clear language;
- accept that maintainers may decline a contribution.

## unacceptable behavior

- harassment;
- discrimination;
- threats;
- doxxing;
- spam;
- impersonation;
- publishing private credentials or vulnerability details;
- repeated unsolicited public actions.

## scope

This policy applies to project spaces and future contribution workflows. Repository owners may add stricter rules for a specific project.

## enforcement

Report concerns privately to the repository owner. The owner will review the report, protect private information, and decide on an appropriate response.
